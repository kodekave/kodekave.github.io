Background patterns · pick by letter

Quiet patterns, made by code

Thirteen generated backgrounds for the white-paper page. Each one is drawn by a few lines of maths with a seed, so every page can have its own and nothing is a stock image. They sit at the edge of perception: noticed when you look for them, invisible when you read. They mix the vintage era (plotter art, punched tape, halftone, printers’ marks) with a clean neo-modern, futuristic geometry.

Use the controls to judge them. Strength sets how visible they are, Fade toward text keeps them to a corner so words stay clear, and Base grid lays the printers’ mark grid under every one so you can see how two layers combine.

How I would use them across the site

One quiet layer on every page, a different generated pattern on each, always faded away from the text. The pattern is made once when the site is built and saved as a small SVG, so it costs nothing to load and nothing moves.

Combinations worth trying

  • Base + one accent: the plus grid at 3% everywhere, then one generative pattern per page fading from a corner. Calm, consistent, and every page is different.
  • Flow + contours: two fields of the same kind, a physical, scientific pair for Home and Research.
  • Schotter on cards: the order-to-disorder grid as the faint texture behind the venture cards.
  • Guilloche on small things: a rosette inside the round portrait badge, or behind “Bridging founders and operations”.
